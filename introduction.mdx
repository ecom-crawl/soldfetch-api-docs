SoldFetch helps you search sold and active eBay listings, inspect individual items, and build resale research tools. Use REST from your application or connect an AI agent through MCP.

<CardGroup cols={2}>
<Card title="Make your first request" icon="bolt" href="/quickstart">Get an API key and search sold listings.</Card>
<Card title="Connect an AI agent" icon="robot" href="/guides/ai-agents">Configure the hosted MCP server or install the eBay skill.</Card>
<Card title="Explore the API" icon="code" href="/api-reference/search">Search, item lookup, jobs, and account endpoints.</Card>
<Card title="Use runnable examples" icon="github" href="https://github.com/ricciflow-api/soldfetch-api-examples">cURL, JavaScript, Python, and Go examples.</Card>
</CardGroup>

<Warning>
Displayed listing prices are not verified accepted-offer amounts. Search sale dates are unverified, and an exact-match filter does not establish product identity. Read [data quality](/concepts/data-quality) before building valuations or date-based reports.
</Warning>

The API base URL is `https://soldfetch.com`. Check [capabilities](https://soldfetch.com/v1/capabilities) for current availability and [status](https://soldfetch.com/status) for service health.
