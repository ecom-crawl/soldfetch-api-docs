# SoldFetch documentation

Public MDX documentation for https://soldfetch.com/docs. `docs.json` configures Mintlify.
Use the live https://soldfetch.com/api/v1/openapi.json contract for endpoint paths and parameters, and https://soldfetch.com/v1/capabilities for current availability.
Use SoldFetch as the brand, API key for credentials, and request or unit for metered usage.
Write concise task-oriented prose and working examples. Document only public behavior; never copy operational notes, service credentials, admin routes, database information, or customer data into this repository.
Keep navigation synchronized with pages. Run `npm test`, `npm run check:live`, and `npx mint validate`; preview before publishing. Changes to main deploy through Mintlify.
